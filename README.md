# Portfolio — Aaron Bueb

Portfolio personnel présentant mon parcours, mes compétences et mes projets.

**Technologies** — React, TypeScript, Vite et CSS.

## Lancer en local

Avec Node.js et npm installés, exécuter les commandes suivantes à la racine du projet.

```powershell
npm.cmd ci
npm.cmd run dev
```

Ouvrir l’adresse affichée par Vite.
